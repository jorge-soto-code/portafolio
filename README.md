# Mi portafolio

Abre `index.html` en tu navegador para ver el portafolio.

Antes de publicarlo, cambia los textos de ejemplo:

- **Tu nombre** y las iniciales `TN`.
- Tu correo, ciudad y enlaces de GitHub y LinkedIn.
- Las tecnologías que ya manejas.
- Los tres proyectos por tus proyectos reales y sus enlaces.

Para publicarlo gratis cuando esté listo, puedes subir esta carpeta a un repositorio de GitHub y activar **GitHub Pages**.
